## 4. Exact Image Replacement Instructions

1. **Format:** Generate files as standard high-resolution JPEGs (`.jpg`) using the Google Flow prompts above.
2. **Naming:** Save each generated image with its exact filename specified in the inventory table (e.g., `ac-hero-technician.jpg`).
3. **Directory:** Place all replacement files directly into:
   ```text
   assets/images/placeholders/
   ```
4. **HTML Update (Optional):** The HTML files currently link to `assets/images/placeholders/ac-*.svg` for crisp, offline, vector fallback. Once your `.jpg` images are saved in `assets/images/placeholders/`, simply find and replace `.svg` with `.jpg` across the 6 HTML files, or keep the existing filenames. Because duplicate `.jpg` placeholders with identical vector fallbacks are also included in the directory, you can simply overwrite the corresponding `.jpg` files!
5. **Dimensions:** Ensure images match the specified aspect ratios (16:9, 4:3, 3:2, or 4:5) to prevent any cumulative layout shifts (CLS).
